# RecurSpec v0.2.0

First-class GitHub Action for running recovery contracts in CI.

## Highlights

- Run RecurSpec from any workflow with `uses: chrisriv10/RecurSpec@v0.2.0`
- No caller-side Node or pnpm setup; bundled Node 24 runtime
- Job Summary with pass/fail/total counts and the recovery table
- Structured step outputs plus optional JUnit and Markdown report files
- Dry-run, case/tag filtering, fail-fast, and seed inputs
- Workflow-command injection hardening for Action logs
- Markdown reporter preserves ambiguity candidate commands (#11)

## Install

```bash
pnpm add -D recurspec@0.2.0
```

## Action

```yaml
- uses: actions/checkout@v4

- uses: chrisriv10/RecurSpec@v0.2.0
  with:
    config: recurspec.yml
```
